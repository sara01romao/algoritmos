MÓDULO 3 — FUNÇÕES E ORGANIZAÇÃO DE CÓDIGO
3.1 Funções

Estudar: definição, parâmetros, return, parâmetros padrão, *args, **kwargs, escopo de variáveis (local x global).

Exercícios de lógica:

1- Crie uma função que verifique se um número é primo.
2- Crie uma função que receba uma lista e retorne uma nova lista sem duplicatas.
3- Crie uma função recursiva para calcular o fatorial.
4- Crie uma função recursiva para a sequência de Fibonacci.
5- Crie uma função *args que receba qualquer quantidade de números e retorne a média.
6- Crie uma função que receba uma string e retorne um dicionário com a contagem de cada caractere.

Projeto: Calculadora com menu de funções — cada operação (soma, subtração, potência, raiz, fatorial etc.) é uma função separada, chamada a partir de um menu interativo.

3.2 Módulos, pacotes e tratamento de erros

Estudar: import, criação de módulos próprios, try/except/finally, exceções customizadas.

Exercícios de lógica:

1- Trate o erro de divisão por zero em uma calculadora.
2- Trate o erro de o usuário digitar letras onde deveria digitar números.
3- Crie uma exceção customizada SaldoInsuficienteError para um sistema bancário simples.
4- Separe um projeto em múltiplos arquivos: main.py, operacoes.py, utils.py.

Projeto: Sistema bancário simples (conta corrente) — depósito, saque (com validação de saldo), extrato e transferência entre duas contas, tudo com tratamento de erros e organizado em módulos.
