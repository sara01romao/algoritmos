MÓDULO 4 — PROGRAMAÇÃO ORIENTADA A OBJETOS (POO)
4.1 Classes e objetos

Estudar: class, __init__, atributos, métodos, self.

Exercícios de lógica:

1- Crie uma classe Retangulo com métodos para calcular área e perímetro.
2- Crie uma classe ContaBancaria com métodos depositar e sacar.
3- Crie uma classe Pessoa com atributos nome/idade e um método que diga se é maior de idade.
--------------------------------------------------------------------------------------------------

4.2 Herança, encapsulamento e polimorfismo

Estudar: herança de classes, atributos privados/protegidos, sobrescrita de métodos, polimorfismo.

Exercícios de lógica:

1- Crie uma classe Animal com método emitir_som() e subclasses Cachorro e Gato que sobrescrevem o método.
2- Crie uma hierarquia Veiculo → Carro, Moto, cada um com atributos específicos.
3- Implemente encapsulamento em ContaBancaria, tornando o saldo um atributo privado acessado por métodos (getter/setter).

Projeto: Sistema de gerenciamento de biblioteca — classes Livro, Usuario e Biblioteca, com métodos para emprestar, devolver e listar livros disponíveis; usar herança para diferenciar LivroFisico e EbookLivro.
