MÓDULO 5 — MANIPULAÇÃO DE ARQUIVOS E DADOS
5.1 Arquivos (texto, CSV, JSON)

Estudar: open(), modos de leitura/escrita, módulos csv e json.

Exercícios de lógica:

1- Leia um arquivo .txt e conte quantas linhas ele tem.
2- Salve uma lista de dicionários em um arquivo CSV.
3- Leia um CSV e calcule a média de uma coluna numérica.
4- Salve e recupere dados de um cadastro em JSON.

Projeto: Sistema de controle de estoque com CSV — cadastra produtos (nome, quantidade, preço), salva em arquivo CSV, permite atualizar estoque e gera um relatório de produtos com baixo estoque.

5.2 Bibliotecas para dados (opcional, se o foco for Data Science)

Estudar: pandas, matplotlib básico.

Exercícios de lógica:

1- Carregue um CSV com pandas e mostre estatísticas básicas (.describe()).
2- Filtre linhas de um DataFrame por uma condição.
3- Gere um gráfico de barras simples com matplotlib.

Projeto: Análise de dados de vendas — a partir de um CSV fictício de vendas, gerar relatório com total vendido por mês e gráfico de evolução.
