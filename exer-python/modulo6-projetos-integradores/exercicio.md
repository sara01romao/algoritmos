MÓDULO 6 — PROJETOS INTEGRADORES (fechamento)

Depois de passar pelos módulos acima, monte 2–3 projetos maiores que integrem várias habilidades:

1- API de tarefas com Flask — CRUD de tarefas com banco de dados SQLite, usando POO e tratamento de erros.
2- Web scraper simples — usando requests e BeautifulSoup, extrair dados de uma página e salvar em CSV/JSON.
3- Jogo da forca ou Tic-Tac-Toe em terminal — usando funções, listas, laços e tratamento de exceções.
4- Automação de arquivos — script que organiza arquivos de uma pasta por extensão automaticamente (bom para praticar os e shutil).
