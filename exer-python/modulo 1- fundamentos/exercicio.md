MÓDULO 1 — FUNDAMENTOS
1.1 Variáveis, tipos de dados e entrada/saída

Estudar: int, float, str, bool, input(), print(), conversão de tipos (int(), str(), float()).

Exercícios de lógica:

1- Peça o nome e a idade do usuário e imprima uma frase formatada com os dois.
2- Peça dois números e imprima a soma, subtração, multiplicação e divisão.
3- Converta uma temperatura de Celsius para Fahrenheit (fórmula: F = C * 9/5 + 32).
4- Peça um valor em segundos e converta para horas, minutos e segundos.
5- Troque o valor de duas variáveis sem usar uma terceira variável auxiliar.

Projeto: Calculadora de IMC — recebe peso e altura, calcula o índice de massa corporal e imprime o resultado formatado com 2 casas decimais.
------------------------------------------------------------------------------------------------------------------------
1.2 Operadores e estruturas condicionais

Estudar: operadores aritméticos, relacionais, lógicos (and, or, not), if, elif, else.

Exercícios de lógica:

1- Verifique se um número é par ou ímpar.
2- Verifique se um número é positivo, negativo ou zero.
3- Dado três números, descubra qual é o maior.
4- Classifique um triângulo (equilátero, isósceles ou escaleno) a partir de 3 lados.
5- Dado um ano, verifique se é bissexto.
6- Faça um programa que simule um caixa eletrônico simples: pergunte o valor e diga a menor quantidade de notas (100, 50, 20, 10, 5, 2, 1) necessárias.

Projeto: Sistema de classificação de notas — recebe 3 notas de um aluno, calcula a média e informa se está Aprovado, em Recuperação ou Reprovado, com faixas de nota definidas por você.
--------------------------------------------------------------------------------------------------------------------------

1.3 Laços de repetição

Estudar: for, while, range(), break, continue, else em laços.

Exercícios de lógica:

1- Imprima os números de 1 a 100.
2- Imprima apenas os números pares entre 1 e 50.
3- Calcule o fatorial de um número.
4- Verifique se um número é primo.
5- Gere a tabuada de um número informado pelo usuário.
6- Some todos os números de 1 até N.
7- Inverta os dígitos de um número (ex: 123 → 321).
8- Desenhe um triângulo de asteriscos com altura N usando laços aninhados.
9- Calcule a sequência de Fibonacci até o N-ésimo termo.

Projeto: Jogo de adivinhação — o programa sorteia um número entre 1 e 100 e o usuário tenta adivinhar, recebendo dicas de "maior" ou "menor" até acertar, contando o número de tentativas
